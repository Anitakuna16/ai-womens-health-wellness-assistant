# AI Women's Health & Wellness Assistant

The AI Women’s Health & Wellness Assistant is an AI-powered assistant developed using AWS PartyRock to provide women with easy access to reliable and educational health and wellness information. It helps users build healthy daily habits by providing personalized suggestions based on their needs and preferences.

## Features

- Nutrition suggestions
- Exercise plans
- Stress management tips
- Sleep recommendations
- Healthy lifestyle guidance

## Technology Used

- AWS PartyRock
- Generative AI
- Prompt Engineering
